# san-shmera — FAQ / Συχνές ερωτήσεις

**Focus / Αντικείμενο:** Calendar and history / Εορτολόγιο και ιστορία

## Where do I download it? / Πού το κατεβάζω;

[Latest stable published release](https://github.com/gs-applabs/san-shmera/releases/latest). Select the official installer and matching SHA-256 file if provided. Read the requirements, limitations and upgrade notes. A hash is an integrity check, not a signature or proof of safety. Do not bypass OS warnings.

## How do I get started? / Πώς ξεκινάω;

Follow release notes, especially the manual upgrade from 1.2.0 or earlier to 1.2.1.

## What are the limitations? / Ποιοι είναι οι περιορισμοί;

Content has documented review status and is not an official historical or religious authority. / Δεν αποτελεί επίσημη ιστορική ή εκκλησιαστική πηγή.

## Where do I find screenshots? / Πού βρίσκω εικόνες;

[Actual Windows CI screenshot gallery](product-snapshots/README.md). Some views use demonstration data. Visual tests are not full functional acceptance tests.

## Can I report a bug or suggest a feature? / Μπορώ να αναφέρω σφάλμα ή να προτείνω δυνατότητα;

[Open an issue](https://github.com/gs-applabs/san-shmera/issues/new/choose). Include your app and Windows versions and steps to reproduce. Redact personal data, credentials and confidential files.

## What is planned? / Τι σχεδιάζεται;

Additional content review, search improvements and visual accessibility.

This is a non-binding direction, not a promised release date. / Ενδεικτική κατεύθυνση, χωρίς δεσμευτική ημερομηνία.
